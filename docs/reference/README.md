# 原始资料归档说明

本目录用于归档项目依赖的**原始资料**，包括课程 PPT、SRS 原文、需求访谈记录、外部标准与参考资料。

## 一、归档目的

- 保留需求与决策的原始出处，便于追溯。
- 避免团队成员各自持有不同版本导致上下文不一致。
- 为 `context.md`、`spec/`、`adr/` 提供事实依据。

## 二、归档规则（占位，待补充）

1. **原始文件只读**：归档文件不得直接修改；如需修订，新增版本并注明来源与变更原因。
2. **命名规范**：
   - 课程资料：`<课程>-<主题>-<日期>.<扩展名>`，如 `SE-第6周-项目启动-2026-10-31.pdf`
   - 需求资料：`SRS-<章节>-<版本>.<扩展名>`
   - 外部参考：`external-<来源>-<主题>.<扩展名>`
3. **大文件说明**：单个二进制文件建议不超过 20 MB；超出时在 README 登记外部链接并注明访问权限。
4. **敏感信息**：禁止归档包含个人隐私、账号口令、密钥的材料；必要时脱敏后归档。
5. **来源登记**：每份资料在下方登记表中的“来源/提供人”列注明出处。
