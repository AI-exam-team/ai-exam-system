## 1. 摘要

本模块接收考试模块已提交的答卷，由教师触发 DeepSeek 按题库已有评分点生成建议分与理由。教师逐题采纳、修改或驳回 AI 建议并填写确认分；整场所有已提交答卷的所有题均复核后，由教师统一发布成绩。学生只能查看本人已发布的确认分与复核意见。

系统只有教师、学生两种业务角色，题型仅支持简答题 `SHORT_ANSWER`、论述题 `ESSAY`。AI 只辅助评分，不自动定分，也不自动发布成绩。

### 1.1 上下游交接

| 来源 / 去向 | 数据与责任 | 本模块约束 |
| --- | --- | --- |
| qbank → grading | 题干、参考答案、题目分值、评分点 ID / 描述 / 分值 | 只读取约定数据，不修改题目或重新分配评分点分值；历史版本取值待 C-01 |
| exam → grading | `AnswerSheet.status=SUBMITTED`，答卷 ID、试卷 ID、学生 ID、逐题答案 | 接收手动或自动交卷结果；不改变答案、提交方式及提交时间，不处理草稿保存 |
| grading → 教师 | 每题 AI 状态、逐点评分依据、AI 建议分、教师确认分及复核信息 | 只允许试卷创建教师访问与操作 |
| grading → 学生 | 已发布的本人逐题 `reviewedScore`、`reviewComment` 及由确认分汇总的总分 | 未发布不可见；不返回 AI 内部结果或其他学生数据 |

一份 `Paper` 对应一场考试。考试发布和截止由 exam 负责；成绩发布由 grading 负责。二者的“已发布”不是同一个状态。

### 1.2 必需的契约与术语

- `GradeResult` 按 `(answerSheetId, questionId)` 唯一，一份答卷每道试题最多一份评分结果。
- `aiStatus` 仅有 `NOT_STARTED`、`PENDING`、`SUCCEEDED`、`FAILED`。范围文档中的“AI_FAILED”是失败场景描述，落到实体字段时使用 `aiStatus=FAILED`，不新增枚举。
- AI 成功结果包含 `rubricHits`、`aiScore`、`aiReason`。每个命中项含 `rubricItemId`、`hit`、`score`、`reason`；每个评分点恰好出现一次。
- 评分点采用二值规则：命中得该点满分，未命中得 0 分。`aiScore` 等于逐点得分之和。评分点分值来自题库，不由 AI 创建或调整。
- 教师复核记录 `reviewedScore`、`reviewedBy`、`reviewedAt`，可填写学生可见的 `reviewComment`。确认分为 `[0, 题目分值]` 内整数；教师确认分不受 AI 二值命中组合限制。
- 成绩逻辑状态为 `NOT_READY → READY → PUBLISHED`；不是 `AnswerSheet.status` 或 `Paper.status` 的新枚举。其存储表达由后续契约 / 设计明确。
- `finalScore` 仅在成绩发布后由该答卷各题 `reviewedScore` 汇总；发布前不得写入，不独立维护另一份成绩表。

## 3. AC（验收条件）

### 3.1 共用验收数据与方式

准备教师 T1、T2 和学生 S1、S2。T1 的试卷 P 含 Q1（简答题 10 分，评分点 R1=6、R2=4）、Q2（论述题 10 分，评分点 R3=10），总分 20。S1、S2 均有已提交答卷；另准备独立草稿答卷测试拒绝路径。除专门测试发布边界外，发布用例在考试已结束、自动交卷完成后执行。

模型结果、超时及非法响应使用可控制的替身测试，确保预期值可复现；另记录一次真实 DeepSeek 调用的端到端证据。真实模型输出不要求每次完全相同，不能以一次调用宣称评分准确率达标。以下是待执行验收条件，并非已通过的测试记录。

### 3.2 可执行条件

| 编号 | Given（前置） | When（操作） | Then（可观察结果） |
| --- | --- | --- | --- |
| AC-1 已交卷才可初评 | T1 操作本人试卷；分别存在 DRAFT、SUBMITTED 答卷 | 对两者分别触发初评 | 仅 SUBMITTED 可进入评分；DRAFT 不调用模型、不生成有效评分，不改变答案；草稿请求返回 409 `ANSWER_NOT_SUBMITTED` |
| AC-2 正常逐点评分 | Q1 初评未开始，模型返回 R1 命中得 6、R2 未命中得 0，两项均有理由，总分 6 | T1 触发且结果通过校验 | `NOT_STARTED → PENDING → SUCCEEDED`；保存完整两项、`aiScore=6` 与整体理由；`reviewedScore` 仍为空，成绩不发布 |
| AC-3 成功结果复用 | Q1 已 `SUCCEEDED`，AI 建议分为 6 | 再次触发或刷新查看 | 复用已有结果，不再次调用 DeepSeek，不新增重复 GradeResult，不改变已有复核分 |
| AC-4 输出结构与二值校验 | 分别模拟无法解析 JSON、字段类型错误、缺点、多点、重复 ID、陌生 ID、缺理由、R1 命中但只给 3 分、逐点合计与 aiScore 不一致 | 系统处理各个响应 | 每个响应均整体拒绝，不部分采纳；标记 FAILED，无可用建议分；解析、字段、映射、命中或合计错误返回 502 `AI_OUTPUT_INVALID`；仅当结构及类型可解析、分数值有效但超出题目范围时返回 502 `AI_SCORE_OUT_OF_RANGE` |
| AC-5 模型异常 | 模拟超过配置超时、上游限流或连接异常、aiScore=-1、aiScore=11（Q1 满分 10） | 初评处理到最终失败 | 标记 FAILED；超时对应 502 `AI_SERVICE_TIMEOUT`，其他上游故障返回 502 `AI_SERVICE_UNAVAILABLE`，分数越界返回 502 `AI_SCORE_OUT_OF_RANGE`；不自动记 0 分，人工复核入口仍可用 |
| AC-6 人工降级 | Q1 已 FAILED，无有效 AI 分数 | T1 人工填写确认分 7 并保存 | 保存 `reviewedScore=7`、T1 和服务端复核时间；AI 状态仍为 FAILED，不伪造 aiScore；该题计为已复核 |
| AC-7 采纳与修改留痕 | Q1 的 aiScore=6，尚未复核 | 分别在独立样本上采纳 6，或不采纳并填写 7、意见“补充要点成立” | 对应保存确认分 6 或 7；均保留 aiScore=6 和原命中理由；记录复核人及时间；意见按提交值保存 |
| AC-8 确认分边界 | Q1 满分 10 | 分别提交 0、10、-1、11、1.5、空值作为正式确认分 | 0 和 10 可保存且计为已复核；其余拒绝且不覆盖原值，不将空值当 0；无效值返回 400 `INVALID_REVIEWED_SCORE`。不能按“分数大于零”判断是否复核 |
| AC-9 未满足发布条件 | P 尚未 CLOSED、没有 SUBMITTED 答卷，或任一已提交答卷存在未复核题目 | T1 发布成绩 | 分别返回 409 `PAPER_NOT_CLOSED`、`NO_SUBMITTED_ANSWER_SHEETS` 或 `GRADE_NOT_FULLY_REVIEWED`；不产生发布记录，所有学生仍不可见 |

| AC-11 发布前后可见性 | S1 查询本人成绩 | 分别在成绩发布前、发布后查询 | 发布前返回 403 `SCORE_NOT_PUBLISHED` 且无分数；发布后只获得本人确认分、复核意见及确认分汇总；接口不返回 aiScore、aiReason、rubricHits，不泄露参考答案或评分点 |
| AC-12 访问隔离 | 已登录 S2 或 T2；另准备失效 JWT 和不存在答卷 ID | S2 访问 S1 结果，T2 访问 / 复核 / 发布 T1 数据；失效 JWT 请求；T1 请求不存在答卷 | 越权返回 403 `FORBIDDEN`，失效 JWT 返回 401 `UNAUTHORIZED`，不存在答卷返回 404 `ANSWER_SHEET_NOT_FOUND`；均不泄露目标数据、不调用模型、不写复核或发布状态 |
| AC-13 重复与迟到请求 | 同一题重复触发，或教师在 AI 处理中先完成人工复核；已发布成绩再次收到发布请求 | 处理请求或回调 | 每题仍只有一个 GradeResult；人工复核后迟到 AI 响应返回 409 `AI_RESULT_DISCARDED`，不得覆盖确认分；重复发布返回 200 和原 `publishedAt`，不产生第二份发布记录；发布后修改返回 409 `GRADES_ALREADY_PUBLISHED` |
| AC-14 空答案 | SUBMITTED 答卷的某题 content 为空字符串 | 教师查看并处理该题 | 该题仍纳入待复核总数，可像其他答案一样触发 AI；AI 不成功时允许教师人工确认 0 分；空答案和 AI 建议 0 分都不自动视为已复核 |

## 4. 功能需求（FR）

初评结果按单题保存和验收。API 只提供逐题触发；若教师选择整卷初评，前端逐题发起请求并逐题展示结果，不新增批量端点。重试单位为单题，单题失败不影响其他题。

| 编号 | 功能与可验证规则 | 对应 AC |
| --- | --- | --- |
| FR-1 评分对象 | 通过约定接口接收 SUBMITTED 答卷，按试卷题目逐题展示作答和评分进度；MANUAL 与 AUTO 交卷同等处理，不新增交卷状态。 | AC-1、AC-14 |
| FR-2 教师触发初评 | 教师按单题触发后，由后端统一 AIService 同步调用 DeepSeek；输入包含题干、参考答案、评分点及学生答案，使用契约中的题目 / 评分点映射。整卷操作由前端逐题调用。 | AC-2 |
| FR-3 严格校验 | 核验评分点 ID 完整且无重复、字段完整、类型正确、二值分数与 hit 一致、总分等于逐点和且范围正确。任何不合格输出整题拒绝，不修补后冒充模型成功结果。 | AC-4、AC-5 |
| FR-4 状态与降级 | 展示 NOT_STARTED / PENDING / SUCCEEDED / FAILED 及失败提示；每题最多 3 次实际模型调用（每次请求最多自动重试 1 次，且仅限可重试网络异常）；失败不等于零分。任一 AI 状态均允许教师人工复核。PENDING 人工复核会以条件更新终止该尝试；迟到响应置为已丢弃且不得覆盖确认分。 | AC-5、AC-6、AC-13 |
| FR-5 逐题复核 | 支持采纳建议分，或修改 / 驳回建议并输入确认分；驳回不能单独代表完成，必须保存有效 reviewedScore。发布前允许再次修改最新确认分；发布后锁定。保留 AI 建议原值，记录 reviewedBy、reviewedAt 及可选 reviewComment。 | AC-6～AC-8、AC-13 |
| FR-6 完成度与发布 | 仅当 Paper 为 CLOSED、至少一份答卷已 SUBMITTED 且每道题均有有效 reviewedScore 时允许发布；0 分有效，缺失 GradeResult 或缺少确认分均未完成。READY 从现有数据推导，不单独持久化。仅试卷创建教师可统一发布，finalScore 由确认分汇总；每张试卷只创建一条 GradePublication。 | AC-9、AC-10、AC-14 |
| FR-7 成绩查询 | 发布前学生不可查询成绩；发布后仅可查询自己的确认分、复核意见和总分。AI 结果仅向该试卷创建教师展示，不能仅靠前端隐藏。 | AC-11、AC-12 |
| FR-8 幂等与保护 | 同一答卷同一题结果唯一，已成功初评复用；最多 3 次实际模型调用、每请求最多 1 次可重试网络重试；条件更新保护并发和迟到结果，发布重复请求返回原记录。候选细节见 ADR-003。 | AC-3、AC-13 |

## 6. 边界与异常

### 6.1 已有错误码与处理

| 场景 | HTTP / code | 必须保持的结果 |
| --- | --- | --- |
| 未登录 / JWT 失效 | 401 `UNAUTHORIZED` | 无数据访问、调用或写入 |
| 访问非本人权限资源 | 403 `FORBIDDEN` | 不泄露他人答案或成绩 |
| 答卷不存在 | 404 `ANSWER_SHEET_NOT_FOUND` | 不创建孤立评分结果 |
| DeepSeek 超时 | 502 `AI_SERVICE_TIMEOUT` | 最终失败标记 FAILED，保留人工通道 |
| JSON 不可解析、评分点不匹配、结构不完整 | 502 `AI_OUTPUT_INVALID` | 整题拒绝，不部分采纳 |
| AI 分数越界 | 502 `AI_SCORE_OUT_OF_RANGE`，待统一契约 R6 措辞 | 不截断成边界分或自动记零 |
| 未完成整场复核即发布 | 409 `GRADE_NOT_FULLY_REVIEWED` | 不发布、不提前写 finalScore |
| 学生查询未发布成绩 | 403 `SCORE_NOT_PUBLISHED` | 不返回任何成绩分值 |

上表是候选业务错误映射。当前候选采用同步 HTTP：初评在同一请求中返回结果或模型错误，不定义 202 受理或轮询语义；最终错误映射待模块评审冻结。

### 6.2 关键边界

1. **零分与缺失分不同**：确认分为 0 表示已复核；null、缺字段、缺评分记录均不表示已复核。
2. **AI 失败与教师复核独立**：FAILED 题可具有有效 reviewedScore；不得为使成绩发布而把 aiStatus 改成 SUCCEEDED。
3. **部分题失败**：保留其他题成功建议，每个失败题都必须取得教师确认分后才能满足整场发布条件。
4. **初评完成不等于复核完成**：即使 AI 给满分也不得自动填入 reviewedScore；教师只打开页面也不算确认。
5. **数据版本边界**：已发布试卷的结构、分值、时间不可改；题目本体与 rubric 的历史版本取值仍依赖 C-01，本文不自行承诺快照或动态引用。
6. **状态名称隔离**：Paper.PUBLISHED 是考试发布，成绩 PUBLISHED 是结果发布；AnswerSheet 始终使用 DRAFT / SUBMITTED，不新增 GRADED 等跨模块状态。
