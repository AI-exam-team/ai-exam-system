## 1. 一句话目标

面向高校课程考试场景，构建一个 AI 辅助主观题考试系统：教师维护简答/论述题题库并组卷发布，学生在线限时作答，系统调用 DeepSeek 按评分点给出建议分，教师逐题复核确认后统一发布成绩。

---

## 2. MVP1 演示路径（唯一验收路径）

```
教师登录
  → 建题（题干、参考答案、评分点及分值）
  → 组卷（选 2~5 题，校验分值）
  → 发布考试（设置开始/截止时间）
  → 学生登录 → 限时作答（草稿自动保存）
  → 手动交卷 或 到点服务端自动交卷
  → 教师触发 AI 初评（逐评分点给建议分与理由）
  → 教师逐题复核（采纳 / 修改 / 驳回并留痕）
  → 整场复核完成后教师统一发布成绩
  → 学生查看本人每题得分与复核意见
```

**判定标准（宁小勿大）**：上述 8 步能由 1 名教师、2 名学生完整跑通，即为 MVP1 达标。说不出这条路径，就是范围太大。

## 4. 模块依赖与端到端职责

```
qbank（题目 + 评分点 + 试卷）
   │  发布试卷（1 份试卷 = 1 场考试）
   ▼
exam（考试窗口、作答、草稿、交卷）
   │  已提交答卷（含答案）
   ▼
grading（AI 建议分 → 教师复核 → 整场发布成绩）
   │
   ▼
学生查看本人成绩
```

锁定规则：

1. `exam` 不得自定义题目与评分点结构，一律引用 `qbank` 契约。
2. `grading` 不得自行计算「评分点分值」，只读取 `qbank` 定义。
3. 跨模块只通过契约传递数据，禁止直接读写其他模块内部数据。
4. 考试发布属于 `exam` 模块；成绩发布属于 `grading` 模块。

## 5. 范围级验收标准（AC）

### AC-S1 演示路径可完整跑通

- **Given** 教师账号已由教师侧初始化，题库为空
- **When** 按第 2 节演示路径完成建题、组卷、发布、作答、交卷、AI 初评、复核、发布成绩
- **Then** 学生在成绩页看到**本人每题教师确认分与复核意见**，全程不需要管理员角色、客观题或自助注册

### AC-S2 越界需求被拒绝

- **Given** 有人提出「客观题自动判分」或「管理员审核试卷」等需求
- **When** 进入需求评审或 PR 评审
- **Then** 依据本文件第 3.2 节直接拒绝，不进入 Backlog

### AC-S3 每个需求有唯一模块归属

- **Given** 任一新增需求或 PR
- **When** 提交评审
- **Then** 必须写明所属模块（qbank / exam / grading / 前置能力）与 Non-Goals 检查结果；无归属或触碰 Non-Goals 的需求不得合并

## 6. 已关闭的待确认项

| 原编号 | 问题 | 决策（2026-11-10） |
| --- | --- | --- |
| TBD-01 | 考试时长与超时交卷 | 发布时设置开始/截止时间；到截止时间由**服务端**自动交卷，逾期不可作答 |
| TBD-02 | 断线与重复提交 | 草稿自动保存可续答；交卷后锁定；重复交卷返回 409 `EXAM_ALREADY_SUBMITTED` |
| TBD-03 | 评分点粒度与 AI 输出 | 每题多个评分点，**分值之和必须等于题目分值**；AI 逐点返回命中与否、理由与该点得分 |
| TBD-04 | AI 失败降级 | 超时/解析失败标记 `AI_FAILED`，保留人工复核通道，不阻塞流程；有限重试，不自动给 0 分 |
| TBD-05 | 复核是否可改与留痕 | 教师可采纳、修改或驳回；保留 AI 原始建议分，记录复核分、复核人与复核意见 |
| TBD-06 | 成绩发布时机与可见范围 | 整场所有答卷所有题复核完成后，教师统一发布；学生可见本人每题教师确认分与复核意见 |

**仍待第 8 周 ADR**：TBD-07 并发规模与费用上限、TBD-08 JWT 有效期与刷新策略。
