## 2. 轮换要求

| 周次 | 要求 |
| --- | --- |
| 第 9 周 | 组长任 Spec Owner；各组确认接口人与 Reviewer；PR 门禁定稿 |
| 第 10 周 | 各组至少完成一次 Spec Owner 与 Reviewer 互换；执行首条 PR 评审演练 |
| 第 11 周 | 交叉评审：qbank ↔ exam ↔ grading；答辩随机抽人以此表为依据 |

## 3. 评审规则

- 作者不得评审自己的 PR；每个 PR 至少 1 名非作者人工评审。
- 涉及 `spec/`、`adr/`、`plans/` 的 PR 必须由组长评审；组长作为作者时由 1 名组员评审。
- 评审记录写入 `docs/review/pr-<编号>.md`。
- 评审不通过时先修订 spec/AC，不在代码中硬改绕过。

## 4. 回填截止

- 各模块组在会后 24 小时内向组长提交：各任务负责人、对接人、Reviewer。
- 同一任务的作者与 Reviewer 不得是同一人。
